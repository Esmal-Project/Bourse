# Stitch branch

این شاخه برای تست پوسته و کدهای Stitch ساخته شده است.

## ورودی‌های فایل ارسالی
- _1: Market Scanner / نمای اصلی بازار
- _2: صفحه جزئیات نماد، عمق سفارش و ریزمعاملات
- _3: نمای کلی بازار و نقشه حرارتی
- _4/_5: پورتفوی و اتصال کارگزاری
- _6: Trader PRO
- _7: Executive Wealth / Multi-Broker
- ai: Smart Liquidity Watch
- three.js: نمونه اتصال TSETMC از طریق CORS proxy
- tsetmc.md: معماری اتصال آنلاین TSETMC

## پیاده‌سازی تست
برای اینکه قبل از دست‌زدن به نسخه اصلی Bourse نتیجه را ببینیم، نسخه Stitch در `stitch/index.html` قرار گرفته است. این صفحه ظاهر کلی Stitch را با یک Market Watch زنده ترکیب می‌کند و ابتدا پروکسی Worker موجود و سپس AllOrigins را امتحان می‌کند.

## نکته
اعداد و سیگنال‌های این نمونه تا زمانی که داده زنده دریافت نشود، ساخته یا حدس زده نمی‌شوند.
